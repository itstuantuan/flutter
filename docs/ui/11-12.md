## 流程与边界

最新启动流程：开屏恢复本地会话；首次使用进入两页引导 → 手机号 → 验证码 → 名字 → 注册对话。
注册对话包含欢迎、正常对话、录音三种状态；跳过后进入首页，先去探索世界进入兴趣选择。
完成状态由 StartupProfileStore 按账号保存在本机，完成后首页聊天固定使用老用户样式；未完成时恢复会话继续注册对话。
其他已登录用户直接进首页，有注册历史但无会话时直接登录。引导页固定 ID 与名字由 StartupProfileStore 保存；
完成引导不代表注册或认证成功。手机号与验证码仍使用原真实账号接口。
首页左下角“逛一逛”进入兴趣选择（340:6246），保存真实选择后进入广场。支持九项兴趣、多选、移除、全选及空选择禁用。
首页和广场聊天、麦克风按钮接入现有本地聊天与录音逻辑。
首页示例发现跳转广场；有本地模拟探索结果时仍打开原有结果详情，并支持带回聊天。
广场返回首页保留卡片位置。广场“更多”按透明度 0 隐藏；
24 分钟、时间线和 `XXXX` 占位文案保留设计稿原文，不代表真实后台活动。

## 新增或调整引导页面

统一列表位于 `lib/features/onboarding/onboarding_pages.dart`，启动流程和独立预览共用该列表。

1. 在 `lib/features/onboarding/` 新建页面组件，接收 `onNext`、`busy` 和 `error`，使用 `OnboardingScaffold` 复用布局与底部按钮；页面自己的视觉和动画由该组件实现。
2. 在列表中添加 `OnboardingPageDefinition(id: '固定唯一ID', nextLabel: '按钮文案', builder: ...)`。列表顺序就是显示顺序，发布后不要重命名 ID。
3. 分页数量、当前位置、按钮文案、翻页和最后一页完成动作由 `OnboardingFlow` 统一处理。不需要修改启动或预览入口。

两页时保留原版分页切图；其他页数自动生成分页点。旧进度兼容 `welcome/world`，新进度使用固定页面 ID，调整顺序后仍能恢复对应页面；已删除的 ID 回退到列表首项。
看完引导不会写入注册成功标记；当前入口用 StartupProfileStore 记录页 ID 与完成状态。已有注册历史或已有会话的用户跳过引导，新增页面不会触发重看。

验证：`flutter test test/features/onboarding test/features/experience/experience_controller_test.dart test/splash_artwork_test.dart`。
